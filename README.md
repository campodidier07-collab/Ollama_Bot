## 🎯 Descripción del Proyecto

Asistente virtual inteligente de arquitectura Full Stack que integra modelos de lenguaje de última generación (**Google Gemini API / Ollama**) con autenticación de usuarios y persistencia de conversaciones en **MongoDB**.

## ⚙️ Características Clave

- **Autenticación y Sesiones de Usuario:** Inicio de sesión y registro seguro con historial personalizado.
- **Respuestas Generativas en Tiempo Real:** Integración directa con la API de Gemini para asistencia técnica y conversacional.
- **Interfaz Dark UI Minimalista:** Diseñada en React con enfoque en legibilidad, velocidad y experiencia de usuario.
